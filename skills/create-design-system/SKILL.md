# Create Design System

## Identify the app

If working in an app project, read its README and relevant source files to understand what the app does. Use that context without asking the user to describe it again.

Otherwise, ask the user what app they want to build and wait for their answer, unless they have already described it. If the project does not make the app's purpose clear, ask for the missing context.

Identify the page or interface to build from the user's request or project context. If unclear, ask the user.

Replace `[page or interface]` and `[app]` below with the identified scope and app, then follow the prompt.

## Prompt

I want you to build me [page or interface] for [app].

Follow this procedure:

Generate a long, random alphanumeric string using a shell script.

Define the creative direction (color scheme, layout, typography, etc.) based on the string. Look beyond the surface for subpatterns, special numbers, anything that inspires you.

Use your judgment to bring this direction to life and make it look great.

Don’t reveal the string in the design. It’s only for your inspiration.
